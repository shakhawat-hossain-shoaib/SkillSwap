# Assignment 1: Interactive Component Build

## Objective:
Create an interactive User Profile Card in React that lets users edit their bio and skill tags dynamically.

## Requirements:
1. Use React functional components and hooks (`useState`).
2. Implement validation ensuring email matches standard pattern.
3. Allow toggling between View mode and Edit mode.
4. Add smooth micro-animations for tag additions.

## Submission:
Push your code to a GitHub repository or zip the `src` folder and submit through the Bootcamp portal.
